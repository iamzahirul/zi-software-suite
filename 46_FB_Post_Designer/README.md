## Features
- **8 templates:** Classic, Big sale, Two colour, Clean, Price tag, Eid / festival, New arrival, Features (tick list) — each adapts to every size.
- **6 sizes:** Post 1:1 (1080), Portrait 4:5, Story 9:16, Facebook page cover, Ad / link 1200×628, YouTube thumbnail. "All sizes" ZIP in one tap.
- **Price card:** price, old price struck through, automatic "২৪% ছাড়" badge (or own text), offer pill, short line, call-to-action button, contact strip (WhatsApp / phone, page, delivery line), shop logo or name.
- **8 Bangla fonts bundled** (work offline): Baloo Da 2, Hind Siliguri, Noto Sans Bengali, Anek Bangla, Atma, Mina, Galada, Tiro Bangla. Bangla digits on/off.
- **Colours:** 8 ready colour sets + own main / second colour.
- **Photo:** whole or fill, zoom; best with transparent PNG.
- **Download:** PNG / JPG (on Android opens the share sheet → Facebook / WhatsApp), saved designs gallery with thumbnails, duplicate.
- **Many at once:** paste a product list from Excel / Google Sheets or open a CSV (e.g. ZI Product Studio export); photos matched by file name (SKU / name) or order; any template or saved design; several sizes; one ZIP.
- Bangla / English app, offline (installable PWA + APK), backup / restore, optional cloud sync of designs, PIN lock, credit.

## Tested
`tsc` clean, all texts in both languages, all 8 templates rendered in post / story / cover sizes and checked visually, every page fits a 375 px phone, demo works offline.
