# ZI Farm — Poultry, Dairy & Fish

Developed by **Zahirul Islam (Rasel)** · https://iamzahirul.com

খামারিদের জন্য: ব্রয়লার, লেয়ার, সোনালী, ডেইরি গাভী, মাছের পুকুর, গরু মোটাতাজাকরণ ও ছাগল — প্রতিদিনের খাদ্য, মৃত্যু, ডিম, দুধ, ওজন; খাদ্যের স্টক; টিকার সময়; বিক্রি ও ক্রেতার বাকি; ব্যাচভিত্তিক খরচ, FCR, কেজি প্রতি খরচ আর লাভ।

- **Online demo:** https://zi-farm-demo.vercel.app → খামারের নাম দিন → "স্যাম্পল ডেটা দেখুন".

- **Android APK:** `apk/`. **Laptop:** demo link → Chrome/Edge "Install". **Web build:** `web/`.

## Features
- **Batches / herds / ponds:** type, shed or pond, start date, starting count, chick / fry / animal cost, pond area; live count, deaths %, age; close a batch when sold.
- **Daily log (one screen for all batches):** feed and kg, deaths, eggs (layer), milk (dairy), sample weight (broiler / fish); yesterday's values shown; "not logged today" warning.
- **Vaccine reminders (poultry):** Marek's, BCRDV, Gumboro, booster, RDV, fowl pox by day of age.
- **Feed store:** feeds with bag size and price, purchases (paid / unpaid), stock in kg and bags, days of feed left at the last 7 days' use, average price per kg.
- **Sales:** birds (kg + heads), eggs, milk, fish, animals, manure; buyer or cash; buyer dues, payments, statement; sale memo (80mm).
- **Expenses:** medicine, vaccine, labour, electricity, litter, transport, vet, rent.
- **Batch P&L:** chick / fry cost + feed (at average price) + expenses vs sales; FCR; cost per kg; laying %; milk per cow.
- **Reports:** batch profit, month by month, daily production (feed, deaths, eggs, milk), expenses by head. Print / CSV.
- Bangla/English, dark mode, PIN lock, backup, works offline at the farm; optional cloud sync (Supabase).
